ФлагЧто делает

--add-dataДобавляет внешние файлы (картинки, звуки) внутрь EXE
Этап 2: Главная проблема
⚠️ Проблема с ресурсами
При разработке
Файлы лежат рядом с кодом ✅

C:\Project\galaxy.jpg
→
Внутри EXE файла
Файлы спрятаны внутри архива ❓

Где их теперь искать?!
⚡ Что происходит при запуске EXE
PyInstaller распаковывает все файлы во временную скрытую папку (например, в Temp).

Ваш код не знает, где эта папка находится. Ему нужен умный помощник.
Этап 2: Главная проблема
💡 Решение: функция-помощник
import sys, os def resource_path(relative_path): """Возвращает абсолютный путь к ресурсу""" try: base_path = sys._MEIPASS except Exception: base_path = os.path.abspath(".") return os.path.join(base_path, relative_path)
СТРОКА 1 — Импортируем модули для работы с системными путями
СТРОКА 3 — Создаём функцию, которая принимает имя файла
СТРОКА 5-6 — Пытаемся найти секретную папку _MEIPASS (существует только в EXE)
СТРОКА 7-8 — Если папки нет (мы в PyCharm), берём текущую папку "."
Этап 2: Главная проблема
🔍 Как работает Try / Except здесь?
TRY — «Попробуй»
Найти папку _MEIPASS

✅ Нашлась? → Мы в EXE!
Используем этот путь
ИНАЧЕ
EXCEPT — «Если ошибка»
Папки _MEIPASS нет

❌ Не нашлась? → Мы в PyCharm!
Используем текущую папку
💡 Аналогия из жизни
🏠 Дома (PyCharm): ты знаешь, что ключи лежат на столе → идёшь и берёшь.

🎒 В школе (EXE): ключи в рюкзаке → открываешь рюкзак и берёшь.

Функция resource_path() — это умный друг, который всегда знает, где искать!
Этап 2: Главная проблема
⚡ Два сценария работы функции
🖥️ Сценарий 1: Запуск в PyCharm
Вызов: resource_path('galaxy.jpg')
1. Ищем _MEIPASS → ❌ Ошибка!
2. base_path = "C:\Project"
3. Результат:
"C:\Project\galaxy.jpg" ✅
📦 Сценарий 2: Запуск EXE файла
Вызов: resource_path('galaxy.jpg')
1. Ищем _MEIPASS → ✅ Нашлась!
2. base_path = "C:\Users\...\Temp\_MEI12345"
3. Результат:
"...\Temp\_MEI12345\galaxy.jpg" ✅

⚠️ Критически важно!
resource_path() оборачивает строку с именем файла, а НЕ результат функции!

❌ resource_path(image.load('galaxy.jpg'))
✅ image.load(resource_path('galaxy.jpg'))
Этап 3: Изменение кода
📖 Разбор функции по строкам
  • 1️⃣ def resource_path(relative_path): — Создаём функцию. relative_path — это просто имя файла
  • 2️⃣ """...""" — Строка документации (помогает понять, что делает функция)
  • 3️⃣ try: — «Попробуй выполнить следующий код, даже если возможна ошибка»
  • 4️⃣ base_path = sys._MEIPASS — Получаем путь к временной папке, созданной PyInstaller
  • 5️⃣ except Exception: — «Если произошла ошибка (мы не в EXE), делай вот это»
  • 6️⃣ base_path = os.path.abspath(".") — Точка "." означает текущую папку проекта
  • 7️⃣ return os.path.join(...) — Склейваем путь к папке и имя файла в один правильный путь!

Этап 4: Сборка
📝 Spec файл — инструкция для сборщика
1
Создаём spec файл (делается один раз):
pyi-makespec --onefile --noconsole shooter_game.py
2
Открываем shooter_game.spec в блокноте и находим datas=[]
datas=[ ('galaxy.jpg', '.'), ('rocket.png', '.'), ('ufo.png', '.'), ('bullet.png', '.'), ('fire.ogg', '.'), ('space.ogg', '.'), ],
Точка '.' означает "положить в корень временной папки"
3
Находим console=True и меняем на console=False
Этап 4: Сборка
🚀 Финальная сборка EXE
1
Открываем терминал (командную строку) в папке проекта:
cd C:\Project\Shooter
2
Запускаем сборку через наш настроенный spec файл:
pyinstaller shooter_game.spec
3
Готовый файл появится в новой папке dist:
C:\Project\Shooter\dist\shooter_game.exe
