Где они теперь?!
⚡ Что происходит
Когда запускаешь exe-файл, PyInstaller распаковывает все файлы во временную папку где-то в недрах Windows.

Код не знает, где искать файлы! Нужен помощник.
Часть 2 — Сборка EXE
💡 Решение — функция-помощник
import sys, os def resource_path(relative_path): """Путь к ресурсу — в PyCharm и в EXE""" try: base_path = sys._MEIPASS except Exception: base_path = os.path.abspath(".") return os.path.join(base_path, relative_path)
СТРОКА 1-2 — Импортируем sys и os для работы с путями
СТРОКА 4 — Создаём функцию, принимающую имя файла
СТРОКА 6-7 — Пытаемся найти папку _MEIPASS (только в EXE)
СТРОКА 8-9 — Если нет — используем текущую папку (PyCharm)
Часть 2 — Сборка EXE
🔍 Try / Except — как работает?
TRY — «Попробуй»
Найти папку _MEIPASS

✅ Нашлась? → Мы в EXE!
Использовать эту папку
ИЛИ
EXCEPT — «Если ошибка»
Папки _MEIPASS нет

❌ Не нашлась? → Мы в PyCharm!
Использовать текущую папку
Аналогия из жизни
🏠 Дома (PyCharm): игрушка в твоей комнате → идёшь и берёшь

🎒 В школе (EXE): игрушка в рюкзаке → открываешь рюкзак и берёшь

⚡ Два сценария работы
🖥️ Сценарий 1: PyCharm
resource_path('galaxy.jpg')
1. Ищем _MEIPASS → ❌ нет
2. base_path = "C:\Project\Shooter"
3. Результат:
"C:\Project\Shooter\galaxy.jpg" ✅
📦 Сценарий 2: EXE файл
resource_path('galaxy.jpg')
1. Ищем _MEIPASS → ✅ есть!
2. base_path = "C:\Users\...\Temp\_MEI12345"
3. Результат:
"...\Temp\_MEI12345\galaxy.jpg" ✅

Часть 2 — Сборка EXE
📖 Разбор каждой строки
  • 1️⃣ def resource_path(relative_path): — Создаём функцию. relative_path — имя файла
  • 2️⃣ """...""" — Документация для человека
  • 3️⃣ try: — «Попробуй выполнить следующий код»
  • 4️⃣ base_path = sys._MEIPASS — Путь к временной папке PyInstaller
  • 5️⃣ except Exception: — «Если ошибка — делаем вот это»
  • 6️⃣ base_path = os.path.abspath(".") — Точка "." = текущая папка
  • 7️⃣ return os.path.join(...) — Склейваем папку + имя файла!

Часть 2 — Сборка EXE
📝 Spec файл — инструкция сборки
1
Создать spec файл:
pyi-makespec --onefile --noconsole shooter_game.py
2
Открыть shooter_game.spec и найти datas=[]
datas=[ ('galaxy.jpg', '.'), ('rocket.png', '.'), ('ufo.png', '.'), ('bullet.png', '.'), ('fire.ogg', '.'), ('space.ogg', '.'), ],
3
Найти console=True и заменить на console=False
Часть 2 — Сборка EXE
🚀 Финальная сборка
1
Открыть терминал в папке проекта:
cd C:\Project\Shooter
2
Собрать EXE через spec файл:
pyinstaller shooter_game.spec
3
Готовый файл появится здесь:
C:\Project\Shooter\dist\shooter_game.exe
