Вопрос: Как распространить игру так, чтобы пользователь мог запустить её без VS Code и Python?

Решение: Упаковать проект в исполняемый файл (.exe), который запускается двойным кликом

📜 Лицензии ПО

Лицензия — документ, регулирующий правила распространения и использования ПО

Закрытые

Проприетарные

Нельзя использовать без согласия разработчика

Пример: MS Office

Открытые

Open Source

Можно скачивать и распространять

Пример: OpenOffice

Свободные

Free

Можно скачивать, распространять и изменять

Пример: VS Code

Creative Commons (CC): «Используйте мой продукт как угодно, но сохраняйте моё авторство»

🧩 Расширения VS Code

Расширение — программа-дополнение, расширяющая возможности VS Code

Полезные расширения:

Python

Подсветка синтаксиса, проверки, подсказки

Bookmarks

Закладки в коде для быстрой навигации

Better Comments

Цветные категории комментариев (#!, # TODO)

Polacode

Красивые скриншоты кода для презентаций

Управление расширениями:

  • Install — установить расширение
  • Disable — отключить (не удаляя)
  • Uninstall — полностью удалить

💻 Терминал и pip

pip — пакетный менеджер Python для установки библиотек

Основные команды pip:

❯ pip help
— список всех команд pip
❯ pip list
— список установленных пакетов
❯ pip install pyinstaller
— установить пакет Pyinstaller

Важно: перед работой убедитесь, что в терминале активна строка (algovenv) или (algoritmika)

Совет: если пакет уже установлен, команда pip install обновит его до последней версии

🗺️ Общая схема сборки .exe

Процесс упаковки проекта в исполняемый файл:

1

Убедитесь, что игра работает

Запустите проект в VS Code и проверьте, что всё работает корректно

2

Замените шрифты на стандартные

Font(None, 36) → SysFont('Arial', 36)

3

Извлеките проект из среды Алгоритмики

Отключите расширение, скопируйте файлы в новую папку

4

Создайте исполняемый файл

Команда pyinstaller --onefile game.py

5

Соберите финальную папку

.exe + картинки + музыка в одну папку result

🔧 Шаги 1-2: Проверка и шрифты

1

Убедитесь, что игра работает

Откройте проект в VS Code через расширение Алгоритмики и запустите игру

2

Замените шрифты на стандартные

Это важно — нестандартные шрифты могут вызвать ошибки при сборке!

❌ Было:

font2 = font.Font(None, 36)

✅ Стало:

font2 = font.SysFont('Arial', 36)
Команда Назначение
font.SysFont('Arial', 40) Создание шрифта на основе системного

📂 Шаг 3: Извлечение проекта

3

Извлеките файлы из среды Алгоритмики

Пошаговая инструкция:

3.1

Отключите расширение Алгоритмики в VS Code и нажмите Reload

3.2

Кликните правой кнопкой по файлу → «Показать в Проводнике» (Windows) / Reveal in Finder (macOS)

3.3

Скопируйте файлы проекта в новую удобную папку на компьютере

3.4

Откройте новую папку в VS Code: File → Open Folder

macOS: пока не запускайте и не проверяйте игру! Дальше нужны дополнительные шаги

🍎 macOS: виртуальное окружение

Виртуальное окружение — изолированное пространство для Python-пакетов

1

Переключитесь на стандартный Python

В левом нижнем углу VS Code кликните на Python → выберите usr/local/bin/python3

2

Создайте виртуальное окружение

❯ python3 -m venv my_venv

Во всплывшем окне одобрите замену окружения на my_venv

3

Активируйте окружение

❯ source my_venv/bin/activate

В консоли появятся круглые скобки (my_venv)

4

Установите нужные пакеты

❯ pip install pygame pyinstaller

⚙️ Шаг 4: Создание .exe файла

4

Создайте исполняемый файл

Откройте терминал в VS Code и выполните команду:

❯ pyinstaller --onefile shooter_game.py

Что делает команда:

Часть команды Назначение
pyinstaller Вызов программы упаковки
--onefile Собрать всё в один файл .exe
shooter_game.py Имя вашего Python-файла

✓ Успех: в конце должно появиться сообщение successfully

Важно: перед вводом команды убедитесь, что в консоли отображается ваше виртуальное окружение (my_venv) или (algovenv)

📁 Шаг 5: Сборка финальной папки

5

Соберите финальную папку проекта

Что куда скопировать:

📂 Откуда брать:

📁 project/ 📁 dist/ 📄 shooter_game.exe ← из dist 🖼️ galaxy.jpg ← из корня 🎵 space.ogg ← из корня 🔫 bullet.png ← из корня

📂 Куда класть:

📁 result/ 📄 shooter_game.exe 🖼️ galaxy.jpg 🎵 space.ogg 🔫 bullet.png 🚀 rocket.png 👾 ufo.png 🔥 fire.ogg

🎉 Готово! Запустите игру двойным кликом из папки result

💡 Совет: папку result можно скопировать на флешку и запустить на любом компьютере

🐧 Особенности запуска на Linux

Процесс создания файла аналогичен Windows, но запуск отличается

По умолчанию: исполняемый файл в Linux можно запустить только из терминала

Способ 1: Запуск по полному пути

❯ /полный/путь/к/shooter_game

Способ 2: Запуск из текущей директории

❯ ./shooter_game

💡 Подсказка: точка и слэш ./ означают «запустить файл из текущей папки»

Windows

Двойной клик по .exe → запуск

Linux

Терминал + команда ./имя_файла
