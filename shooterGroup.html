📦 Что такое группа спрайтов?

sprite.Group() — это контейнер, который хранит множество спрайтов и позволяет управлять ими одновременно

Зачем нужны группы?

  • В игре много врагов и пуль — их нельзя хранить в отдельных переменных
  • Нужно одной командой обновить всех врагов или нарисовать все пули
  • Нужно проверять столкновения между группами (пуля vs враг)

🛠️ Создание групп

# Создаём пустую группу спрайтов
monsters = sprite.Group()
bullets = sprite.Group()

# Заполняем группу врагов
for i in range(1, 6):
    monster = Enemy(img_enemy, randint(80, win_width - 80), -40, 80, 50, randint(1, 5))
    monsters.add(monster)
Шаг 1

Создаём пустую группу через sprite.Group()

Шаг 2

В цикле создаём спрайты и добавляем их в группу через add()

Важно: группа bullets создаётся пустой — пули добавляются в неё динамически, когда игрок стреляет

➕ Метод add() — добавление спрайта в группу

group.add(sprite)

Добавляет один спрайт в группу

Примеры использования:

Добавление врага 
monster = Enemy(...)
monsters.add(monster)

При старте игры и после уничтожения

Добавление пули 
def fire(self):
    bullet = Bullet(...)
    bullets.add(bullet)

При каждом выстреле игрока

Особенность: один спрайт может находиться сразу в нескольких группах одновременно

🔄 Метод update() — обновление всех спрайтов

group.update()

Вызывает метод update() у каждого спрайта в группе

# В основном цикле игры:
ship.update()       # один спрайт — вызываем напрямую
monsters.update()   # все враги — через группу
bullets.update()    # все пули — через группу

Что делает update() у каждого класса?

Enemy.update()

Двигает врага вниз, проверяет выход за экран

Bullet.update()

Двигает пулю вверх, удаляет при выходе

Player.update()

Обрабатывает нажатия стрелок

Важно: метод update() должен быть определён в каждом классе спрайта, иначе группа не сможет его вызвать

🎨 Метод draw() — отрисовка всех спрайтов

group.draw(surface)

Рисует все спрайты группы на указанной поверхности (окне)

Параметр метода:

Параметр Тип Описание
surface Surface Поверхность для отрисовки (обычно window) 
# В основном цикле игры:
ship.reset()            # рисуем корабль (один спрайт)
monsters.draw(window)   # рисуем ВСЕХ врагов
bullets.draw(window)    # рисуем ВСЕ пули

Как работает: метод берёт self.image и self.rect каждого спрайта и вызывает blit() для каждого

💀 Метод kill() — удаление спрайта из всех групп

sprite.kill()

Удаляет спрайт из всех групп, в которых он состоит

Примеры использования:

# В классе Bullet — пуля исчезает при выходе за экран
def update(self):
    self.rect.y += self.speed
    if self.rect.y < 0:
        self.kill()  # удаляем из группы bullets
# При перезапуске игры — удаляем все пули и врагов
for b in bullets:
    b.kill()
for m in monsters:
    m.kill()

Важно: после kill() спрайт перестаёт существовать в группах — его больше не обновляют и не рисуют

💥 Метод groupcollide() — столкновение двух групп

sprite.groupcollide(group1, group2, dokill1, dokill2)

Проверяет столкновения между всеми спрайтами двух групп

Параметры метода:

Параметр Тип Описание
group1 Group Первая группа (например, monsters)
group2 Group Вторая группа (например, bullets)
dokill1 bool True — удалять спрайты из group1 при столкновении
dokill2 bool True — удалять спрайты из group2 при столкновении 
# Пуля и монстр при столкновении ОБА исчезают
collides = sprite.groupcollide(monsters, bullets, True, True)

💥 groupcollide() — как использовать результат

# Проверяем столкновения
collides = sprite.groupcollide(monsters, bullets, True, True)

# collides — это словарь: {монстр: [пули, которые его попали]}
for c in collides:
    # Этот цикл выполнится столько раз, сколько монстров подбито
    score = score + 1
    
    # Создаём нового монстра взамен убитого
    monster = Enemy(img_enemy, randint(80, win_width - 80), -40, 80, 50, randint(1, 5))
    monsters.add(monster)

Разные варианты параметров dokill:

True, True

Оба спрайта исчезают (наш случай)

True, False

Монстр исчезает, пуля остаётся

False, False

Никто не исчезает (только проверка)

🎯 Метод spritecollide() — столкновение спрайта с группой

sprite.spritecollide(sprite, group, dokill)

Проверяет столкновения одного спрайта со всеми спрайтами группы

Параметры метода:

Параметр Тип Описание
sprite Sprite Один спрайт для проверки (например, ship)
group Group Группа спрайтов (например, monsters)
dokill bool True — удалять спрайты из группы при столкновении 
# Проверяем столкновение корабля с любым монстром
if sprite.spritecollide(ship, monsters, False) or lost >= max_lost:
    finish = True  # проиграли
    window.blit(lose, (200, 200))

Параметр dokill = False: корабль не исчезает при столкновении — просто фиксируем факт проигрыша

📊 Итоговая таблица методов групп

Метод Назначение Параметры
Group() Создаёт пустую группу Нет
group.add(sprite) Добавляет спрайт в группу sprite — спрайт для добавления
group.update() Вызывает update() у всех спрайтов Нет
group.draw(surface) Рисует все спрайты группы surface — окно отрисовки
sprite.kill() Удаляет спрайт из всех групп Нет
groupcollide(g1, g2, dk1, dk2) Столкновения двух групп dk1, dk2 — удалять ли спрайты
spritecollide(s, g, dk) Столкновение спрайта с группой dk — удалять ли спрайты группы
